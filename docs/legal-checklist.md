# 사이트 법정 표시 체크리스트 (2026-09-21)

`alreadymorning.com` 이 법적으로 **반드시 표시해야 하는 것**과 **하지 않아도 되는 것**을 정리한다.
이슈 #10(디자인 개편)에서 "넥슨 푸터에 있는 항목을 우리도 다 해야 하는가"를 조사한 결과다.

> 이 문서는 법률 자문이 아니다. 매출·이용자 규모가 아래 **재검토 트리거**를 넘으면 다시 확인한다.

---

## 1. 반드시 해야 하는 것 — 전부 반영 완료

| 항목 | 근거 | 현재 위치 |
|---|---|---|
| 개인정보처리방침 | 개인정보 보호법 제30조 | `/privacy.html` (전 서비스 단일 방침) |
| 사업자 정보 표시 | 전자상거래법 제10조 | 전 페이지 푸터 — 상호·대표·사업자등록번호·통신판매업 신고번호·주소·전화·이메일 |
| 확률형 아이템 확률 표시 | 게임산업법 제33조 제2항 (2024-03-22 시행) | `/odds.html` — 게임별 탭 |
| 이용약관 | 전자상거래법·약관규제법상 사실상 필수 | `/terms.html` |
| 소비자 불만 처리 연락처 | 전자상거래법 | `support@alreadymorning.com` · 070-7954-6929 |

### 확률 공시는 사실 면제 대상일 수 있다

게임산업법상 **최근 3년간 연평균 매출액 1억원 이하인 중소기업이 제작·배급하는 게임물**은
확률정보 표시 의무에서 제외된다. 벌써아침은 현재 이 기준에 걸릴 가능성이 높다.

**그래도 `/odds.html` 은 유지한다.** 면제라고 공시를 내리면 이용자 신뢰가 떨어지고,
매출이 기준을 넘는 순간 다시 만들어야 한다. 자율 공시로 계속 간다.

---

## 2. 하지 않아도 되는 것 — 넥슨 푸터에 있지만 우리는 대상이 아니다

### 청소년보호정책 / 청소년보호책임자 — ❌ 의무 아님

정보통신망법 제42조의3. 지정 의무는 **아래 두 조건을 모두 충족**할 때 생긴다.

1. 일일평균 이용자 10만명 이상 **또는** 연 매출액 10억원 이상
2. **청소년유해매체물을 제공·매개**하는 정보통신서비스 제공자

우리 게임은 청소년유해매체물이 아니고 규모도 미달이라 해당 없음.
없는 청소년보호책임자를 페이지에 적는 것이 오히려 허위 표시가 된다.

### 게임시간선택제 — ❌ 의무 아님 (중소기업 제외)

게임산업법 제12조의3(게임과몰입 예방조치)은 살아 있으나,
**시행령 제8조의3이 「중소기업기본법」상 중소기업(영상·방송통신 및 정보서비스 업종)이
제공하는 게임물을 예방조치 대상에서 제외**한다.

- 벌써아침은 개인사업자이며 중소기업 기준 미달 → **게임시간선택제 의무 없음**
- 단, **연 매출액 50억원 이상** 중소기업은 제12조의3 제1항 **1호(본인인증)·2호(법정대리인 동의)** 는 해야 한다
- 게임시간선택제(이용시간 제한)는 중소기업이면 매출과 무관하게 제외

⚠️ 확인 포인트: 게임 소프트웨어 개발·공급업의 한국표준산업분류는 58212(출판업 중분류)다.
시행령이 말하는 "영상·방송통신 및 정보서비스 업종"이 대분류 J 전체(58~63)를 가리키는지
중분류 59~63 만 가리키는지는 매출이 커져 실익이 생길 때 문체부(044-203-3268)에 확인한다.
현재는 규모 자체가 미달이라 결론이 달라지지 않는다.

### 게임IP사용가이드 · 고객센터 · 전체서비스 — ❌ 전부 자율

- **게임IP사용가이드**: 저작물 이용 가이드라인. 법적 의무 아님. 스트리밍·2차 창작 문의가 실제로 들어오면 그때 만든다
- **고객센터**: 별도 센터 운영 의무는 없다. "문의처 표시" 의무만 있고 `support@` 로 충족
- **전체서비스**: 사이트맵. 푸터 4단 사이트맵이 그 역할을 한다

## 3. 출시 전까지 남은 것

### 게임물 등급 표시 — 🟡 등급 반영 완료, 내용정보 미정

게임산업법 제33조 제1항: 게임물마다 **제작·배급자의 상호, 등급, 게임물내용정보**를 표시해야 한다.
인터넷 홈페이지도 대상이다(같은 조 제2항).

등급은 Play 의 IARC 설문을 통한 **자체등급분류**로 정해진다(한국은 Google 이 자체등급분류사업자).
청소년이용불가 등급이 아니면 별도 GRAC 신청은 통상 불필요하다.

| 게임 | 등급 | 사이트 표시 |
|---|---|---|
| 던전 컴퍼니 | **12세이용가** | ✅ `/dungeon` 히어로 하단 |
| 던전 크러시 | **전체이용가** | ✅ `/crush/` 히어로 하단 |
| 마왕님 야근 사수 | 미정(개발 중) | 등급 확정 후 추가 |

🔴 **남은 것: 게임물내용정보.** 등급과 상호는 표시했으나 내용정보(선정성·폭력성·사회반규범성·
언어의 부적절성·공포·약물·사행행위 중 해당 항목)는 아직 받지 못했다.
Play Console 의 IARC 설문 결과에 함께 나오므로 확인 후 `.ratingband` 블록에 한 줄 추가한다.
**없는 항목을 임의로 적지 않는다.**

참고: 현재 등급 표식은 CSS 로 그린 색상 배지다(전체=녹색, 12세=노랑, 15세=주황, 청소년이용불가=빨강).
게임물관리위원회 공식 등급 마크 이미지를 써야 한다면 `.grade` 를 `<img>` 로 교체하면 된다.

## 4. 재검토 트리거

아래 중 하나라도 넘으면 이 문서를 다시 검토한다.

| 지표 | 임계값 | 발생하는 의무 |
|---|---|---|
| 최근 3년 연평균 매출 | **1억원 초과** | 확률형 아이템 확률 표시가 **법적 의무**가 된다 (현재는 자율) |
| 연 매출 | **10억원 이상** | 청소년보호책임자 지정 검토 (청소년유해매체물 제공 시) |
| 일일평균 이용자 | **10만명 이상** | 위와 동일 |
| 연 매출 | **50억원 이상** | 본인인증·법정대리인 동의 확보 의무 |
| 중소기업 기준 이탈 | — | 게임시간선택제 전면 적용 |
