Game 01

던전 컴퍼니

방치형 RPG Android · Web 출시 예정

부제는 “마왕성 키우기”. 마왕성을 하나의 회사처럼 운영하는 것이 이 게임의 뼈대입니다. 간부를 채용하고 몬스터 직원을 육성해 성으로 몰려오는 용사를 막아냅니다.

방치형(idle) 장르라 조작이 계속 필요하지 않습니다. 플레이어가 할 일은 무엇에 투자할지 결정하는 것입니다. 앱을 닫아도 진행이 계속되고, 다시 열면 그동안 쌓인 금화와 마석을 받습니다.

진행 상황은 서버에 저장됩니다. 기기를 바꾸거나 앱을 다시 설치해도 계정을 연결해 두었다면 마왕성은 그대로 남아 있고, 다른 플레이어와 마왕 랭킹으로 경쟁할 수 있습니다.

게임 시작하기 개인정보처리방침

주요 기능

  • 마왕 강화와 마왕 권능 — “강제 야근”, “퇴근 금지 결재”, “KPI 폭주” 등 회사생활을 비튼 능력으로 전투력을 올립니다
  • 간부 채용 · 몬스터 직원 육성 — 30종 이상의 간부와 40종 이상의 몬스터로 방어선을 구성합니다
  • 보스(본사 감사) 전투 — 스테이지를 올리며 감사관을 격파하고 마석을 확보합니다
  • 방치 수익 — 접속하지 않은 시간만큼 금화가 쌓이고, 다시 열 때 정산됩니다
  • 마왕 랭킹 — 전투력 기준으로 다른 플레이어와 순위를 겨룹니다

게임 화면

계정과 데이터

게스트로 바로 시작할 수 있고 로그인은 선택입니다. 구글 계정 로그인은 진행 상황 보관과 랭킹 참여 두 가지 목적뿐이며, 요청하는 정보는 이메일 주소와 기본 프로필(이름·프로필 사진)뿐입니다. 광고 식별자를 이용한 추적은 하지 않습니다.

앱 안에서 언제든 계정 삭제를 요청할 수 있고, 요청 시 서버의 게임 데이터와 계정이 함께 파기됩니다. 자세한 기준은 개인정보처리방침에 있습니다. 문의는 support@alreadymorning.com.

Game 02

던전 크러시

매치3 퍼즐 매치3 롤플레잉 Android 출시 예정

유저는 마왕. 마왕성에 쳐들어오는 침입자를 매치3 퍼즐로 막아내세요.

익숙한 매치3, 낯선 보스전 — 같은 몬스터 3개를 맞춰 터뜨리는 익숙한 규칙. 4개를 맞추면 줄무늬, ㄱ자·ㅗ자로 맞추면 폭탄, 5개를 맞추면 「마왕의 눈」이 됩니다. 챕터 끝에는 침입자 보스가 기다립니다. 보스의 얼굴 캔디를 부숴 마왕성 밖으로 밀어내세요.

간부를 모아 보스를 쉽게 — 스페셜 판에서 별 3개를 받으면 던전 컴퍼니의 간부가 합류합니다. 간부가 많을수록 보스전이 쉬워집니다.

개인정보처리방침 계정·데이터 삭제 요청

부담 없이

  • 로그인 없이 바로 시작. 원하면 구글 계정을 연결해 진행도를 저장하고 기기를 바꿔도 이어서 플레이할 수 있습니다.
  • 첫 도전은 하트를 쓰지 않습니다. 하트는 시간이 지나면 다시 채워집니다.
  • 광고는 플레이 도중에 끼어들지 않습니다. 하트가 부족할 때 광고를 보고 이어갈 수 있고, 광고 제거를 구매하면 배너·전면 광고가 사라집니다.

게임 화면

「던전 컴퍼니」의 직원과 간부들이 이번엔 마왕성을 지킵니다. 던전 크러시에는 가챠가 없습니다.

Game 03

마왕님 야근 사수

아레나 서바이버 Windows 개발 중

결재를 요구하며 몰려드는 몬스터 직원에게 결재 반려 도장을 던지고, 마왕님이 18:00 정시 퇴근하는 것이 목표인 한 판 15분짜리 데스크톱 게임입니다.

같은 마왕성 세계관을 쓰지만 장르와 플랫폼이 다릅니다. 방치형인 던전 컴퍼니와 달리 손이 계속 바쁜 실시간 아레나입니다.
