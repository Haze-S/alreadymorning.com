던전 크러시 — 계정 및 데이터 삭제 요청

개발자: 벌써아침 · 앱: 던전 크러시

1. 앱 안에서 바로 삭제하기 (권장)

앱 실행 → 설정 → 계정 → 계정 삭제. 확인 후 계정 정보와 클라우드에 저장된 게임 진행도가 즉시 삭제됩니다.

2. 앱을 지웠거나 앱에 접근할 수 없을 때

support@alreadymorning.com 으로 아래 내용을 보내 주세요. 본인 확인 후 영업일 기준 7일 이내에 처리하고 회신합니다.

  • 제목: [던전 크러시] 계정 삭제 요청
  • 구글 계정을 연결한 경우: 연결한 구글 계정 이메일
  • 게스트(익명)로만 이용한 경우: 앱 설정 화면에 표시되는 사용자 ID (앱을 지운 뒤에는 확인이 어려우므로 앱 내 삭제를 권장합니다)

3. 삭제되는 항목과 보존되는 항목

  • 삭제: 계정 정보(사용자 식별자, 연결한 구글 계정 정보), 클라우드 세이브(게임 진행도)
  • 법령상 보존: 결제·환불 등 거래 기록은 전자상거래법에 따라 5년 보존 후 파기
  • 기기 안에만 저장된 게임 데이터는 앱을 삭제하면 함께 삭제됩니다

자세한 내용은 개인정보처리방침을 참고해 주세요.
